## Real full-byte composition

The [assembler](../qualification/native_capacity_paced_profile_bundle_v1.py)
is integrated into the real managed launcher's authored native branch. It
receives the genuine source-verified profile planner and pinned resource planner,
not a manager, SDK, namespace or transport substitute. Callers must supply these
trusted verified controls; accepting an arbitrary object is not an authorization
or producer-authentication mechanism.

One operation binds all requested lane/role pairs, their complete child profile
bytes, one complete parent profile and the actual canonical native-entry plan.
Children remain the unchanged 543-row R4 profiles. The distinct parent contains
549 rows and its original paced seal. The genuine parent producer compares each
entire canonical child payload, including source rows, bindings, context and
role URLs; a matching replacement hash alone is insufficient.

The assembler adds no full child-profile JSON decoding, whole registry/tree
copy or second parent serialization. It detaches only small bounded reference
records. Required full private profiles are not abbreviated, source rows are
not omitted, and the original two-lane workload is not reduced to pass a check.

## Cross-artifact closure

The child list must contain exactly PAYER then SERVICE for every requested lane,
in workload order. A reordered role, foreign lane or extra/missing pair refuses.
The canonical entry plan is derived from that same ordered, fully checked list;
it cannot silently use a separate set of child references.

Private references must name the declared same store's `objects/<digest>` path
and that declared task's exact `lanes/NN/payer` or `service` root. Task scratch
paths follow the pinned manager's `tasks/<task-id>/scratch` schema. Traversal,
relative paths, unrelated stores and digest/filename mismatches refuse.

These path/schema checks are lexical DATA binding, NOT a filesystem ownership,
lease, inode, mount, symlink or CAS observation. The real managed branch still
obtains and rechecks actual roots/objects through the approved owned manager.
A declared private mode or independent inode cannot authenticate physical roots.
The genuine parent producer separately rejects declared root/reference aliases.
