## Actual binding and measurement semantics

Funding and warmup still use the actual pair without pacing. Measured source
entries use the genuine paced owner's global FIFO/minimum-gap admission.
The exact additional configuration is
`pacing: { minimumStartGapMs }`, an integer in 1-1000.
Entered operations retain their original pair and completion accounting.
STOP requests the service-window stop without waiting for an entered original.
The genuine owner retains its fixed drain and close contract.

The final fresh balance/writer-trace barrier reads the genuine windowed phase
through `owner.inspect().core.phase`. Reading the outer paced inspection's
nonexistent direct phase would silently omit final trace collection.
Fresh balances and writer pages still come from the actual pair.
Parent pacing/IPC timing and service-child writer timing are not merged.

The ordinary report retains the genuine paced report, including separate queue
wait and source-entry distributions. This is closed-loop minimum-gap admission,
NOT a fixed offered rate. Private evidence has separate capabilities:

- `privateParentTimingEvidence()`: the genuine inner windowed trace capsule.
- `privatePacedTimingEvidence()`: the cached paced capsule plus inner trace.

Neither private read adds a clock observation, execution or recorder replay.
