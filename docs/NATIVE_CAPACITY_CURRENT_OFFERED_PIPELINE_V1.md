## Finite resource planning and storage optimization

The global calendar is not divided equally between lanes. A fast lane can take
every offer, so every lane reserves its complete warmup plus global-offer
capacity. Unused funded reservations are not dispatches or replay authority.
Busy rejections and scheduler misses remain separate original counters.

The checked default plan has one lane, one warmup and four global offers:
five service calls are reserved on that lane. The proposed task reservation is
38 MiB, Node stdout is 458,752 bytes and its outer timeout is 53 seconds.
These are conservative DATA reservations, not allocated bytes, performance
measurements, OS quotas or native permission.

Both Node and OpenSSL reserve the full 1 MiB manager stderr ceiling. A command's
stdout override does not lower stderr under an existing shared-store policy.
The policy is compared, never rewritten. The 10 GiB production floor, safety
margin, metadata allowance and all other recognized store reservations remain
additive. No root is initialized, adopted, replaced or cleaned.

Complete profiles are retained once through manager CAS references. Required
TLS alias paths use independent APFS clones, not hard links or implicit copies.
No source/package tree is copied. The outer reader parses the retained original
compact frame in place and does not serialize or clone the whole capture again.
It recomputes private child writer attribution and percentiles from available
intervals. Unavailable raw aggregate timing is not claimed as independent proof;
parent and child clock domains remain separate.

A full reservation that exceeds the entry cap refuses; it does not shrink
samples, divide the workload or retry. Lost acknowledgement, incomplete streams,
unknown child closure, storage HOLD or a metadata refusal remain distinct from
a matching component DATA record. Child-created files are never automatically
adopted or deleted to manufacture cleanup success. Metadata/stream recovery
must not restart an already completed native command.

mutations. The outer test controller launched an isolated Python DATA process,
not a native application child.

## Authority and remaining roadmap

Neither the current one-clean native allowance nor any old R4 allowance admits
this new P4 managed path. There is no new native authority in this increment.
Native execution still needs a separately admitted exact finite scope and
successful production storage admission. Do not bypass a reservation refusal,
restore old runtime bytes, relabel old results, or retry a payment or run.

The complete native controller is authored but unexecuted and unqualified.
Current runtime, interruption/lost-ACK/late-socket/HELD-store qualification,
real-load/error/latency/balance-pressure/sustainable-capacity measurements and
independent chain/provider/economic/operator acceptance remain open.
Integration remains GO; native pilot and production remain NO-GO.
