bytes to the genuine timer-parent profile producer, the workload entry plan
and the entire resource selection. Its caller must authenticate the producer;
an object's shape is not provenance. No compact/fake application namespace,
child JSON normalization, source tree copy or second whole expected child

application-source byte pins. It prepares the real outer-V4 DATA validator.
Package rows remain declarations; neither installed packages nor the Node
binary are opened. There is deliberately no native execution or storage
preflight branch. Native, manager, root, package, Node and old approval flags
are not accepted. This source entry cannot consume the old unpaced R4 grant.

The exact selected default remains two lanes, one warmup plus four measured
calls per lane. All five complete profiles total 971,802 bytes; the complete

the 16-lane fixture has 32 child profiles and a 215,652-byte parent. Shared

The controls reject missing/extra/reordered roles, foreign run/lane/root/CAS
references, aliased declared root identities, changed whole child bytes even

relabelled versions and every changed effect or policy field. The default

4 MiB metadata reservation, 10 GiB floor and full timer reservation are not

## Branch and CI boundaries

The source-only entry, manifest and 102-case source harness are development-only:
they require the reviewed timer-parent application selection, not all of which
is on main. Do not run that harness on main and call missing dependencies a
qualified application graph.

Main receives only the standalone standard-library DATA bundle, this document
and the source-bound result. The bundle imports no development application or
profile producer at import time; its pure assembly API needs an authenticated
caller-supplied producer. It does not change the default payer or enable a
native path. The unchanged automatic hosted profile has 27 DATA/component cases;
it does not host these 102 Python controls or qualify native behavior.
