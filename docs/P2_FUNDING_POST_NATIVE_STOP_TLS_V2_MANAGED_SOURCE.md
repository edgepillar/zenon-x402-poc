## Implemented

- A separate managed controller composes the unchanged nine-row, seven-case
  native harness manifest with five exact outer Python control pins.
- Default mode reads repository source only. It never reads the private manager,
  private storage root or Node binary, imports native JavaScript, or opens TLS.
- Explicit pre-native and execute modes have new manifest/source-seal selection
  tripwires. These are not human authorization, an OS sandbox or replay authority.
- The frozen full-sibling capacity reader accounts for every recognized sibling
  store, up to 256 distinct roots; no old 16/32-root truncation is used. Its
  unchanged task-record identity cache avoids rereading unchanged metadata.
- Native context admission would hash each executable once, then compare all nine
  file-identity fields before commands. This avoids repeated large Node hashes;
  it is a source design, not a measured native performance result.
- The production floor remains 10 GiB, plus the unchanged 1 GiB safety margin,
  4 MiB task reservation, 4 MiB metadata reservation and all sibling reservations.
  A new empty root never exempts other roots or overrides a capacity refusal.
- One owned task would retain exact repository inputs, one OpenSSL capture and
  one Node capture as verified objects. Small explicit TLS component copies are
  private, quota-accounted and retained. No recursive package or duplicate ZIP
  capture, evidence hardlink, root initialization or historical cleanup exists.
- Actual exit, complete stream EOF and exact digest/size references are required.
  Seven ordered TAP results, all zero failure/skip/TODO totals, owner observations
  and actual fixture closure are checked. Forced socket destruction cannot become
  a clean result; an unobserved late socket path remains unqualified.
- Normal task closure and cleanup disposition are evaluated separately. CLOSED
  or component success cannot turn HOLD into cleanup success. Failure/UNKNOWN
  command receipts are preserved without automatic retry or helper mutation.

The inventory is a conservative cooperative snapshot, not an atomic multi-store
OS lock. Selection flags, source digests and DATA checks do not enforce a network
sandbox or grant permission for private-root admission or native execution.
