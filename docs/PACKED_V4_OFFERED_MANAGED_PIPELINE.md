## Resource and qualification boundary

The complete resource reservation still requires a 38 MiB task quota, 10 GiB
production free-space floor, 1 GiB safety margin and 4 MiB metadata reservation
plus other stores' reservations. No quota was lowered based on the packed
recorder's reference count. The source controller preserves bounded streams,
owned task/command receipt handling and UNKNOWN failures without retry,
replacement, automatic child-file adoption or cleanup.

This is implemented and source/DATA-checked native wiring. It is **not a native
SDK/HTTPS/SQLite run**, ordinary installed-namespace qualification, authenticated
time, successful resource closure, sustainable throughput or production proof.
The driver source does not grant authority. No old clean/R4/V3 finite native
allowance was consumed or transferred to the packed V4 family. Hosted main CI
remains a separate 27-control profile; it does not execute this pipeline suite.
The source guards and permission flags are not an OS/network sandbox.
