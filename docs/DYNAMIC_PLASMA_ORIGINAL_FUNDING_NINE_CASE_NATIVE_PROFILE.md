## Reusable read-only constructor

[The Python control](../qualification/dynamic-plasma-original-funding-nine-case-profile-plan.draft.py)
uses only the standard library. It takes explicit application/package roots and
expanded content pins; it never imports application packages, opens SQLite,
writes a file, creates a task, spawns a child or contacts a network. It checks
file type/owner/link/identity before, during and after reads; content, LF count,
SHA-256 and Git blob must match before a row enters the private plan.

It deliberately supports only the current restricted POSIX-path alphabet.
For scoped package paths, it emits literal @ instead of Python Path.as_uri's
percent-encoded form, while preserving the preload's strict canonical-URL
check. This is a source-informed choice based on the versioned
[Node 24.19 pathToFileURL implementation](https://github.com/nodejs/node/blob/v24.19.0/lib/internal/url.js#L1544),
**not an observed native round-trip or resolver result**. Unsupported paths
are refused, not copied or aliased.

private profile digest. That is planning execution, not a replay of a native
