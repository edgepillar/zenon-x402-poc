# Owned window writer trace

The window trace now has an explicit owned-sample implementation. Its inner
coverage owner validates the same original bindings, page framing, independent
completion, ordering and sticky refusal rules without keeping another copy of
every duration. The outer window owner keeps the classified bracket/inside
samples and sorts its private arrays directly during finalization.

This removes duplicate recording work from the full source candidate. Raw page
validation, exact window classifications, nearest-rank summaries, incomplete
withholding and public final report fields remain preserved. The original
cohort and window modules stay unchanged for their historical recipes.
