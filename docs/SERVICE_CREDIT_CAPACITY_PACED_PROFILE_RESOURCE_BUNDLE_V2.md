The planner includes three balance observations and six raw BEGIN/END events per
lane: at most 48 observations/96 events across sixteen lanes. They are the real
source recorder's existing callback brackets, not new clocks or balance reads.

Separate allowances cover the one raw balance capsule/context, one scalar
recording, one DATA-check summary and each complete lane metric. These are added
to the retained single-copy core/paced timing reservations. The balance clock
domain includes final writer-trace paging; it is neither SQL nor L1 latency.

Source-shaped maximum-width JSON controls exercise 39-digit timestamp/metric
strings, 128-character lane IDs and all event fields against the explicit byte
allowances. These inert maxima are NOT observed native trajectories, timestamp
authentication or a native memory/serialization benchmark.

For the complete existing two-lane default workload, the proposed calculation is:

- 15,360 bytes of additional balance capsule/report/check/lane allowances;
- 1,177,856 bytes of capture reservation and a 1,179,648-byte stdout limit;
- a separate 65,536-byte complete entry-plan reservation;
- 71 MiB task quota plus 4 MiB metadata quota, a 10 GiB free-space floor,
  1 GiB safety margin and all OTHER task reservations still to be admitted.

The calculation happens to retain a 72-second proposed Node bound and 71 MiB task
quota. Equality with old numbers does NOT transfer an old approval, measured
resource result, storage admission or native authority to this changed source.
The default stdout rounding leaves 1,792 bytes above the calculated reservation;
that is policy headroom, not a proven bound on actual native output or heap.

Both Node and OpenSSL stdout/stderr streams remain reserved. All full private
profiles, original SQLite/pin/key/signature/nonce/child effect ceilings and the
fixed measurement window remain in the proposal. Pacing is not appended as an
extra measurement wait. An oversized capture refuses without reducing lanes,
calls, samples, rows or evidence, and without an automatic retry.
