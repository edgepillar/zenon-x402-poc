Restoring old application bytes or refreshing an old manifest's hashes would not
qualify the current implementation. The previous offered parent source candidate
still expects that historical child graph and must not be called current-source
native evidence. Its old files, manifests and results remain unchanged.

This new selection starts from the actual current 123-application/404-package

current delta manifest as a source input. The resulting graph has 153 application

All 153 current application files were read-only checked at their exact bytes.

## Canonical private profile production

The [new producer](../qualification/native_capacity_current_role_profiles_v4.py)
runs the real pinned Python metadata helpers and expands the complete current
selection. It emits canonical V4 role-profile bytes in memory, retaining the
current source seal and manifest pins. No role root or profile file is opened or
created by the DATA factory. Root/source/node identities supplied in DATA tests
remain declared even if a caller claims to have observed them.

Captured inputs and runtime data are detached from caller mutation. Foreign
UIDs, hardlinks, noncanonical identities, changed/missing/reordered source rows,
redirected imports, legacy source seals, extra authority and invalid roles or
root/context data are refused. A profile is not an execution grant.

Large source/runtime/binding fields are serialized three times at preparation
and then reused. In the actual DATA control, 32 sequential profiles reused
203,262 shared canonical bytes, with zero large-table reserializations during
role planning and zero source/package tree copies. Total returned bytes across
that test were 6,543,404, not files written or simultaneous resident memory.
Each profile is capped at 524,288 bytes and the shared cache at 1 MiB.

The optional installed-source builder is read-only and hashes the existing Node
once per complete source context. It was not run here; the test does not claim
that hash, installed package qualification, native timing or an RSS bound.
